# Nutriboard

NutriBoard is a personal cookbook app designed for individuals to document, organize, and manage their recipes. 
Users can log in to access their personal collection, create custom culinary entries, manage their user profile, and easily filter, edit, or save their favorite dishes.

# Run the project
npm install
npx expo start
